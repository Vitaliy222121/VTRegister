# VTRegister — все настройки и значения по умолчанию

**Русский** · [English](CONFIG.en.md)

Справочник собран автоматически из файлов настроек внутри jar, поэтому значения по умолчанию всегда совпадают с релизом. Файлы создаются в `plugins/VTRegister/` при первом запуске; при обновлении недостающие параметры дописываются вместе с описаниями, твои значения сохраняются.

[Назад к полному руководству](GUIDE.ru.md)

### `session`

Сессия (автовход без пароля)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `session.duration_seconds` | `7200` | Сколько секунд действует доверенная сессия после входа (7200 = 2 часа) |
| `session.auto_login_by_ip` | `false` | Автовход, если IP игрока совпадает с доверенным. ⚠️ За прокси без IP-forwarding включать опасно — см. proxy.known_proxy_ips |
| `session.ip_prefix_octets` | `0` | Совпадение IP для автологина по префиксу: 0 = точное совпадение, 3 = /24 (динамические IP), 4 = точное. Значения 1-2 не поддерживаются и поднимаются до 3. IPv6 при префиксе — совпадение /64. Префикс сравнивается только с последним IP аккаунта. ⚠️ Ослабляет привязку: любой клиент той же подсети получит сессию! |
| `session.invalidate_on_restart` | `true` | Рестарт сервера убивает IP-сессии: после перезагрузки все игроки обязаны войти заново (антиспам-реконнект ботами после рестарта). false — сессии переживают рестарт в пределах duration_seconds |

### `ip_limit`

Лимит аккаунтов с одного IP Защита от мультиаккаунтов и ботов: с одного IP можно завести не больше max_accounts аккаунтов (считаются аккаунты, созданные с этого IP или последний раз входившие с него). Новый ник сверх лимита получает отказ при входе и при /register; в уже созданные аккаунты входить можно всегда. За прокси без проброса реальных IP лимит не работает (у всех один адрес). Мобильный интернет часто даёт один IP многим людям — если новички жалуются на отказ, подними max_accounts.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `ip_limit.enabled` | `true` | включить лимит |
| `ip_limit.max_accounts` | `3` | сколько аккаунтов можно на один IP |

### `antibot`

Проверка на бота (многоэтапная) Игрок попадает в отдельный ПУСТОЙ мир (нулевая нагрузка) и проходит этапы. Во время проверки напоминания и таймаут авторизации не работают.

### `global_blacklist`

Пусто = каждый сервер с VTRegister спрашивает пароль сам. |
| `warn_misconfigured` | `true` | Лимиты по IP. Если перед прокси стоит HAProxy/TCPShield БЕЗ PROXY protocol (haproxy-protocol / proxy_protocol), у всех игроков один IP — поставь per_ip_per_minute: 0 и max_online_per_ip: 0. Раз в минуту писать в консоль, если auth_servers/after_login_server указывают на несуществующие серверы. false — не напоминать. |

### `connection_limit`

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `connection_limit.per_ip_per_minute` | `8` | Подключений с одного IP в минуту (0 = без лимита). Проверенные IP не считаются. |
| `connection_limit.max_online_per_ip` | `4` | Одновременно в сети с одного IP (0 = без лимита) |
| `connection_limit.global_per_second` | `25` | Больше подключений в секунду на весь прокси = атака ботов (0 = выкл) |
| `connection_limit.attack_seconds` | `120` | Сколько секунд длится режим атаки: пускаем только проверенные IP |
| `connection_limit.verified_ip_hours` | `72` | Сколько часов IP считается проверенным после успешного входа |

### `ping_check`

Проверка пинга: настоящий клиент сначала видит сервер в списке серверов (пинг), бот обычно подключается сразу. off — выкл; attack — только во время атаки (рекомендуется); always — всегда (новые игроки без пинга получат просьбу обновить список серверов и зайти снова).

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `ping_check.mode` | `attack` | off / attack / always |
| `ping_check.window_seconds` | `600` | сколько секунд пинг «действует» |

### `messages`

Тексты для игроков: & — цвета; перевод строки — два символа: обратный слеш и n

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `messages.ping_first` | `'&eДобавь сервер в список серверов, обнови список и зайди снова.'` | сообщение игроку, который зашёл без пинга в списке серверов |
| `messages.switch_denied` | `'&cСначала войди в аккаунт: &f/login <пароль>'` | сообщение при попытке сменить сервер до входа |
| `messages.command_denied` | `'&cЭта команда доступна после входа: &f/login <пароль>'` | сообщение при запрещённой команде прокси до входа |
| `messages.no_auth_server` | `'&cСервер авторизации недоступен. Попробуй зайти через минуту.'` | сообщение, когда нет доступного сервера входа |
| `messages.attack` | `'&cСервер отражает атаку ботов.\n&fЗайди через пару минут — вернувшихся игроков пускаем сразу.'` | сообщение во время режима атаки |
| `messages.too_fast` | `'&cСлишком частые подключения с твоего IP. Подожди минуту.'` | сообщение при слишком частых переподключениях |
| `messages.too_many_online` | `'&cС твоего IP уже играет слишком много аккаунтов.'` | сообщение, когда с одного IP слишком много игроков |
