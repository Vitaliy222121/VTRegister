# Changelog

Все заметные изменения VTRegister документируются здесь.
Формат: [Семантическое версионирование](https://semver.org/lang/ru/).

## [1.1.5] — 2026-09-20

### Добавлено
- **Антибот v3**: этапы `PUZZLE` («убери лишних» + слово-подтверждение + отсчёт 3-2-1),
  `MATH` (пример в чате/боссбаре, выкл по умолчанию), `SECRET` (ловушка на чит-команды
  `.bind`/`.help`/`#bro` или свои/случайные, выкл по умолчанию).
- **Очередь 3 режимов**: `none` / `bossbar` / `lobby` — платформа-ожидание с паркуром
  (лёгкий/средний/сложный), боссбаром позиции, голограммой и настраиваемым чатом.
- **PvP-зона в лобби**: координаты в конфиге, сундук с рефиллом лута каждые N сек
  (формат `МАТЕРИАЛ:ЗАЧАР:УР:КОЛ`), голограмма-предупреждение.
- **Ставки в очереди** (`queue_steal`): убийство в PvP = +N позиций, смерть = −N.
- **SLOTS-рывки камеры**: сервер дёргает камеру N раз и ждёт Look-пакеты живого клиента.
- **Блок-путь**: случайный зигзаг на каждого игрока, сундук со спец-инструментом,
  лимит падений до кика.
- **Фоновые проверки**: лимит move-пакетов за тик, кик за полёт там, где нельзя.
- **Аварийный режим**: запасная арена в небе основного мира + спам предупреждений
  в консоль (10 раз / 5 мин — настраивается).
- **Настраиваемые боссбары**: цвет/шаблон основного + второй рекламный бар.
- **Bedrock**: `bedrock_skip_slots` — у Geyser-игроков вырезается этап слотов.
- Полёт для ждущих в лобби (`queue_flight`), скрытие игроков друг от друга.
- `INSTRUCTION_RU.txt` / `INSTRUCTION_EN.txt` копируются в папку плагина.
- Бэкапы БД (`advanced.yml → database_backup`), лимиты на IP/SMTP, вотчдог сброса кэша.

- **Распределённая защита целостности**: все 45 классов сверяют доменный токен
  с общим отпечатком сборки (методы + поля + конструкторы каждого класса +
  маркер `vtregister.dat`). Гейт при загрузке класса + вплетённые проверки в
  горячих путях (хеширование, вход, сессии, хранилище, телепорты, 2FA,
  антибот, команды, API). Вырезание защиты требует фактического
  переписывания всего проекта — fail-closed при любом несовпадении.
- **Байткод-подпись сборки** (`Sec.s()` + `vtregister.sig`): SHA-256 по байтам
  всех `.class` (включая inner) + `plugin.yml` + маркер. Патч тела метода,
  вырезанный `throw`, правка `plugin.yml` или маркера — подпись ломается.
  `IntegrityGuard` сверяет её с `EXPECTED2` двумя независимыми путями.
  Структурный отпечаток (`tok()`) переведён на разбор constant pool —
  отпечаток больше не зависит от classpath сервера (фикс ложных срабатываний
  на серверах с дополнительными зависимостями вроде floodgate).
- **Лобби-ожидание 25x25**: шахматный пол из кирпичей, стеклянный бортик,
  светящиеся углы с фонарями, золотая метка спавна и табличка-подсказка.
- **Лобби расширено до 45x45** (60+ игроков): морские фонари в полу,
  угловые башни с фонарями, паркур удлинён до 14 площадок, PvP-арена
  35x35 вплотную к южной стене с воротами, колоннами-укрытиями, сундуком
  и голограммой. Новая опция `antibot.lobby_first_seconds` (по умолчанию
  8): все заходящие сначала ждут в лобби, потом идут на проверку.
  `influx.burst` по умолчанию поднят до 64 (под лобби на 60 игроков).
- Вторая очередь входа на сервер (`entry queue`) после проверки на бота,
  экстренная защита при наплыве (батчи по 5, лимит 15, кик с сообщением
  о нагрузке), отсчёт подготовки арены, генерация изображений пазла,
  Bedrock-выключатель по умолчанию off.

### Исправлено
- **Игрок застревал в паутине/слизне после FALL**: при переходе на
  не-физический этап платформа перестраивается в твёрдую, игрок
  телепортируется в центр арены (капча/клик/пазл — на чистой площадке).
- **Паутина**: повторный подброс при «зависании» больше не срабатывает
  на игроке, который нормально тонет в паутине — бесконечный цикл убран.
- **CLICK (5-я проверка)**: кнопка пересылается в чат каждые 8 сек, всегда
  дублируется командой /rpverify — сообщение больше не тонет в чате.
- **Подготовка**: во время отсчёта перед 1-м этапом позиция заморожена —
  игрок не мог уйти с платформы в пустоту до старта проверки.
- **PvP-зона**: арена теперь примыкает к лобби (раньше была отделена
  36 блоками пустоты — физически недостижима), внутри зоны игроки
  видят друг друга даже при queue_hide_players: true.
- **Ложные кики за полёт**: `kick_flyers`/`queue_kick_flyers` теперь карают
  только полёт БЕЗ `allowFlight` (разрешения сервера) и требуют 3 тика
  подряд — игроки с выданным другими плагинами полётом больше не слетают.
- **Тест на физику (FALL)**: отсчёт падения стартует ПОСЛЕ реального
  телепорта (раньше — с постановки в планировщик: лаг/пинг съедал запас
  и честных игроков кикало за «слишком быстрое» падение). Порог времени
  увеличен, добавлен повторный подброс при «зависании» клиента и защита
  от засчитывания приземления до фактического телепорта.
- **Крах при отключении IntegrityGuard**: `onEnable` теперь останавливается
  сразу после отключения плагина — `IllegalPluginAccessException` устранён.
- **Ложные кики на SLOTS**: grace-период для запоздалых пакетов + приём любой
  реальной смены слота (колесо и цифры 1–9), до 3 попыток.
- **Обход заморозки**: `setTo` в `onMove` теперь выполняется до любых проверок —
  исключение больше не открывает движение в обычном мире.
- **Дроп предметов до входа** и смежные ивенты закрыты.
- **CAMERA**: медленное вращение теперь считается (суммарные обороты `camera_turns`),
  быстрое не проскакивает; `camera_linearity` ловит ботов.
- Мир проверки не создавался при `load: STARTUP` — убрано, мир создаётся на POSTWORLD.
- Повторная попытка создания мира каждые 30 сек после неудачи (раньше — никогда).
- Дублированный лог «Режим прокси» ×3 при старте.
- Все «мёртвые» ключи `advanced.yml` теперь реально подключены к коду.

### Безопасность
- IntegrityGuard: эталонный отпечаток обновлён под новый набор методов.
- Во время очереди/проверки заблокированы ВСЕ команды (лобби/reconnect/алиасы/
  неймспейсные), кроме внутреннего `/rpverify`.

## [1.1.0] — базовый релиз
- Ядро авторизации: PBKDF2, защищённый ввод пароля, сессии, 2FA TOTP, email-восстановление.
- Хранилища: YAML, SQLite, MySQL, MariaDB, PostgreSQL + кэш.
- Антибот v2 (FALL/CAMERA/SLOTS/CAPTCHA/CLICK/BLOCK), пустой мир проверки.
- Импорт из AuthMe/LoginSecurity, PlaceholderAPI, прокси-режим, Folia-планировщик.
