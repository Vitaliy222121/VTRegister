================================================================================
RegisterPlugin - Инструкция по настройке прокси (BungeeCord / Velocity)
================================================================================

СОДЕРЖАНИЕ:
1. Что такое прокси-режим
2. Автоопределение прокси
3. Ручная настройка в config.yml
4. Настройка телепорта на другой сервер
5. Безопасность (IP и секретный ключ)
6. Примеры конфигураций

================================================================================
1. ЧТО ТАКОЕ ПРОКСИ-РЕЖИМ
================================================================================

Прокси-режим позволяет использовать RegisterPlugin на серверах, подключенных к:
- BungeeCord (классический прокси для Minecraft)
- Velocity (современный быстрый прокси от PaperMC)

В этом режиме плагин:
- Сохраняет точку входа игрока (где он появился при подключении)
- Может телепортировать игрока на другой сервер сети после авторизации
- Защищает от несанкционированных подключений через проверку IP

================================================================================
2. АВТООПРЕДЕЛЕНИЕ ПРОКСИ
================================================================================

Плагин АВТОМАТИЧЕСКИ определяет тип прокси из spigot.yml:

Для Velocity (spigot.yml):
settings:
  velocity-support:
    enabled: true
    online-mode: true
    secret: "your-velocity-secret"

Для BungeeCord (spigot.yml):
settings:
  bungeecord: true

Если автоопределение не сработало, используйте ручную настройку в config.yml

================================================================================
3. РУЧНАЯ НАСТРОЙКА В CONFIG.YML
================================================================================

Откройте plugins/RegisterPlugin/config.yml и найдите секцию:

# Включить прокси-режим вручную (если авто не сработало)
proxy_mode: true

# Тип прокси: "bungeecord" или "velocity"
proxy_type: "bungeecord"

================================================================================
4. НАСТРОЙКА ТЕЛЕПОРТА НА ДРУГОЙ СЕРВЕР (ЛОББИ)
================================================================================

После авторизации/регистрации плагин может отправить игрока на другой сервер:

В config.yml:

proxy_server:
  enabled: true              # ВКЛЮЧИТЬ телепорт на другой сервер
  server_name: "lobby"       # Название целевого сервера в прокси
  lobby_address: ""          # IP:порт лобби (необязательно, см. ниже)
  auto_detect_name: true     # определить имя сервера по lobby_address
  transfer_timeout_seconds: 8
  safe_transfer: true        # неуязвимость + запрет падения во время переноса
  fallback_to_lobby_location: true

Как работает:
1. Игрок подключается к серверу авторизации
2. Вводит /login или /reg
3. После успешной авторизации → автоматически отправляется на "lobby"

ВАЖНО: Название сервера должно совпадать с именем в конфиге прокси!

--------------------------------------------------------------------------------
4.1. АВТООПРЕДЕЛЕНИЕ ИМЕНИ ПО IP (lobby_address)
--------------------------------------------------------------------------------
Если лобби стоит на другом IP/порту, можно не искать его имя вручную:

  lobby_address: "10.0.0.5:25566"   # адрес лобби из конфига прокси
  auto_detect_name: true

Плагин спросит у прокси список серверов (BungeeCord: GetServers + ServerIP)
и сам подставит имя сервера, у которого совпадает IP:порт.

Если имя определить не удалось (прокси не ответил, Velocity без
bungee-plugin-message-channel) — используется server_name.

--------------------------------------------------------------------------------
4.2. БЕЗОПАСНЫЙ ПЕРЕНОС (игрок не падает и не умирает)
--------------------------------------------------------------------------------
Пока прокси переключает сервер, игрок:
  • становится неуязвимым (setInvulnerable);
  • не может упасть (allow-flight + сброс fall distance);
  • стоит на безопасной точке: lobby-локация → точка входа → спавн мира.

Если перенос не сработал за transfer_timeout_seconds, плагин пишет
предупреждение в консоль и оставляет игрока на этом сервере
в безопасной точке (fallback_to_lobby_location: true).

--------------------------------------------------------------------------------
4.3. VELOCITY
--------------------------------------------------------------------------------
Velocity понимает BungeeCord-канал только если в velocity.toml включено:

  bungee-plugin-message-channel = true

Без этого автоопределение и Connect работать не будут — используйте
server_name и убедитесь, что плагин стоит на каждом сервере сети.

Для BungeeCord (config.yml прокси):
servers:
  lobby:
    motd: '&1Just another BungeeCord'
    address: localhost:25566
    restricted: false

Для Velocity (velocity.toml):
[servers]
lobby = "localhost:25566"
try = ["lobby"]

================================================================================
5. БЕЗОПАСНОСТЬ (IP И СЕКРЕТНЫЙ КЛЮЧ)
================================================================================

Чтобы защититься от обхода авторизации, включите проверку IP:

proxy_security:
  enabled: true
  secret_key: "my-secret-key-123"    # Секретный ключ для проверки
  allowed_ips:
    - "127.0.0.1"                   # Локальный IP (для тестов)
    - "192.168.1.100"               # IP вашего BungeeCord/Velocity
    - "10.0.0.5"                    # Дополнительные IP прокси

Как это работает:
- Плагин проверяет IP-адрес игрока при подключении
- Если IP не в списке allowed_ips → подключение отклоняется
- При телепорте на другой сервер добавляется секретный ключ в сообщение
- Другие серверы могут проверить этот ключ

УЗНАТЬ IP прокси:
На сервере с прокси выполните: /version или посмотрите в консоли при запуске
IP будет указан как "Listening on /0.0.0.0:25577"

Для VPS/выделенного сервера:
- Укажите внешний IP сервера
- Или "127.0.0.1" если все на одной машине

================================================================================
6. ПРИМЕРЫ КОНФИГУРАЦИЙ
================================================================================

--- ПРИМЕР 1: Простая настройка BungeeCord ---

config.yml:
proxy_mode: true
proxy_type: "bungeecord"

proxy_server:
  enabled: true
  server_name: "main"

proxy_security:
  enabled: false   # Безопасность отключена


--- ПРИМЕР 2: BungeeCord с защитой по IP ---

config.yml:
proxy_mode: true
proxy_type: "bungeecord"

proxy_server:
  enabled: true
  server_name: "hub"

proxy_security:
  enabled: true
  secret_key: "super-secret-2024"
  allowed_ips:
    - "127.0.0.1"
    - "203.0.113.45"   # IP вашего BungeeCord


--- ПРИМЕР 3: Velocity с телепортом ---

config.yml:
proxy_mode: true
proxy_type: "velocity"

proxy_server:
  enabled: true
  server_name: "survival"

proxy_security:
  enabled: true
  secret_key: "velocity-secret-key"
  allowed_ips:
    - "127.0.0.1"
    - "198.51.100.20"  # IP вашего Velocity


--- ПРИМЕР 4: Без телепорта на другой сервер ---

proxy_mode: true
proxy_type: "bungeecord"

proxy_server:
  enabled: false   # Игрок остается на этом сервере

lobby:
  enabled: true   # Телепорт в точку внутри этого мира
  world: "world"
  x: 0
  y: 100
  z: 0

ЧАСТЫЕ ВОПРОСЫ
================================================================================

Q: Игрок не телепортируется на другой сервер!
A: Проверьте:
   1. proxy_server.enabled: true
   2. Название сервера совпадает с именем в конфиге прокси
   3. Прокси работает и сервер доступен
   4. В консоли нет ошибок

Q: Как узнать IP моего прокси?
A: Выполните на сервере с прокси:
   Linux: ip addr show
   Windows: ipconfig
   Или посмотрите в панели управления хостингом

Q: Можно ли использовать одинаковый secret_key на всех серверах?
A: Да, это рекомендуется для дополнительной защиты

Q: Работает ли это с пиратскими (offline-mode) серверами?
A: Да, но настройте IP-защиту обязательно!
