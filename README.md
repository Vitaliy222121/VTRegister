# VTRegister (RegisterPlugin) v1.1.1

Плагин авторизации и защиты аккаунтов для Minecraft-серверов: **Spigot / Paper / Purpur /
Pufferfish / Leaf / Folia** и форки, версии **1.16.5 → 26.x+**.

Главное отличие от типовых решений — **пароль физически не попадает в консоль и логи**,
а защита плагина лицензируется (см. `LICENSE`) и проверяется на целостность.

---

## Быстрый старт (3 шага)

1. Скачай `VTRegister-v1.1.1.jar` со вкладки **Releases** и положи в папку `plugins/`.
2. Открой `plugins/RegisterPlugin/config.yml` — там сверху блок «БЫСТРЫЙ СТАРТ».
   Обычно достаточно проверить `security.command_logging: "fix"` и `antibot.enabled`.
3. Сообщения правь в `plugins/RegisterPlugin/lang/ru.yml` (или `en.yml`).

Всё. Комментарии в конфиге не теряются при обновлениях: плагин дописывает только новые ключи.

## Что внутри

### Безопасность пароля
- **Защищённый режим**: `/reg` → пароль следующим сообщением в чат; сообщение перехватывается
  на `LOWEST` и стирается до того, как его увидят другие плагины и чат.
- **Незащищённый режим** (`/reg пароль`): плагин честно предупреждает, что пароль попал
  в логи, и **дважды** просит подтверждение, прежде чем принять его.
- **Защита от логирования ядром**: строка `ник issued server command: /reg пароль` пишется
  NMS **до** события `PlayerCommandPreprocessEvent`, поэтому плагин:
  - перехватывает команды и исполняет их сам (ядро пароль не видит);
  - правит `spigot.yml → commands.log: false` (`security.command_logging: fix`);
  - ставит log4j-фильтр, вырезающий такие строки из логов.
- **Хеши**: PBKDF2-HMAC-SHA512, 200 000 итераций, соль 32 байта, опциональный pepper,
  константное сравнение, автоматический rehash.
- **Хеширование вне главного потока**: PBKDF2 выполняется в отдельном пуле, сервер не лагает.

### Проверка на бота (антибот)
- Отдельный **пустой мир** с аренами на каждого игрока (нулевая нагрузка,
  `VoidGenerator`, `autoSave`/`keepSpawnInMemory` выключены).
- Этапы (каждый включается/выключается, у каждого свой таймаут):
  `FALL` (реальная физика: платформы SLIME/COBWEB/HONEY — боты отскок не воспроизводят) →
  `CAMERA` (накопить N полных оборотов камеры; медленно можно, с паузами; линейность
  ловит роботов) → `SLOTS` (свои переключения + анти-NoSlotChange: сервер сам меняет
  слот и дёргает камеру, ждёт живые пакеты клиента) → `CAPTCHA` (код в чат) →
  `CLICK` (клик по сообщению) → `PUZZLE` («убери лишних» в GUI + слово-подтверждение
  + отсчёт 3-2-1) → `MATH` (пример, выкл) → `SECRET` (чит-команды `.bind`/`#bro`,
  выкл) → `BLOCK` (случайный зигзаг-путь, спец-инструмент из сундука, лимит падений).
- Фоново: лимит move-пакетов за тик, кик за полёт там, где нельзя, таймауты этапов.
- Игрок в проверке **полностью пустой** (инвентарь и опыт прячутся и возвращаются),
  неуязвим, при смерти возвращается на арену.
- **Очередь 3 режимов** (`queue_mode`): `none` — сообщение с позицией; `bossbar` —
  боссбар «Очередь N/M»; `lobby` — общая платформа-ожидание: паркур 3 уровней,
  голограмма, настраиваемый чат, полёт, скрытие игроков друг от друга.
- **PvP-зона в лобби** (выкл по умолчанию): свои координаты, сундук с рефиллом лута
  каждые N секунд, голограмма-предупреждение; `queue_steal` — убийство = +N позиций
  в очереди, смерть = −N.
- **Аварийный режим**: мир не создался → запасная арена в небе основного мира +
  предупреждения в консоль N раз каждые M минут. Ботов не пропускаем молча.
- **Bedrock**: `bedrock_skip_slots` вырезает Java-специфичный этап у Geyser-игроков.
- Во время проверки **нет спама** «введи /reg» — напоминания и таймаут включаются после.
- Подробная инструкция: `INSTRUCTION_RU.txt` / `INSTRUCTION_EN.txt` (копируются
  в папку плагина при первом старте).

### Защита ДО входа (`antibot.guard`)
- Рейт-лимиты подключений (общий и на IP), attack-mode при всплеске входов.
- Фильтр ников по регулярке (отсекает `Player12345678`).
- Лимит аккаунтов на IP (мультиаккаунты), временный бан IP после провала проверки.
- Reconnect-челлендж в attack-mode.

### Изоляция неавторизованных
Блокируются: движение/повороты, чат, команды (кроме разрешённых), блоки, урон (в обе стороны),
инвентарь, дроп/подбор, еда, крафт, зачарование, наковальня, починка, книги, рыбалка,
стрижка, армор-стенды, транспорт, кровати, полёт, порталы, телепорты (все, включая плагинные —
кроме санкционированных), опыт, potion-эффекты, смерть (инвентарь и опыт сохраняются).
Неавторизованные игроки скрыты друг от друга.

### Аккаунты и хранилище
- **YAML** (`data/accounts.yml`) по умолчанию — как в 1.0.x, ничего переносить не нужно.
- **SQLite** (`data/accounts.db`) — компактнее и быстрее на больших базах.
- **MySQL / MariaDB / PostgreSQL** — общая база для сети серверов, свой пул соединений,
  SSL, префикс таблиц. Драйвер PostgreSQL скачивается автоматически.
- Предзагрузка аккаунта при подключении (`AsyncPlayerPreLoginEvent`) — в главном потоке
  нет ни одного запроса к базе.
- Атомарная запись YAML (временный файл + move) — данные не теряются при падении.

### Миграция с других плагинов
`/authadmin import` — читает и переносит аккаунты из:
- **AuthMe** (`$SHA$`, `$SHA512$`, `$MD5$`, `$BCRYPT$`),
- **LoginSecurity** (BCrypt, с сохранением UUID),
- своего старого `accounts.yml`,
- универсального `import.yml`.

Игроки входят **своими старыми паролями** — после первого входа пароль автоматически
перехешируется в PBKDF2.

### 2FA (TOTP)
`/2fa on` — Google Authenticator и совместимые. Вход: пароль → код.
`/2fa off`, `trust_minutes` для доверия на время сессии.

### Почта и восстановление
`/email <адрес>` — подтверждение кодом; `/recover` — код на почту и смена пароля
без участия админа (SMTP из коробки, без внешних библиотек).

### Премиум-автологин
`premium.enabled: true` — на лицензионном сервере UUID совпадёт с Mojang, пароль не нужен.
На пиратке эффекта нет (UUID другой) — так и задумано.

### Спавны
`/authadmin setspawn prelogin|postlogin|firstjoin` — безопасная зона до входа,
точка после входа и для новичков (хранится в `data/spawns.yml`).

### Прокси
BungeeCord / Waterfall / Velocity: автоопределение, `known_proxy_ips` (защита автологина
по IP), firewall по `getRealAddress` (не пускать напрямую), отправка в лобби после входа
с **автоопределением имени сервера по IP** (`lobby_address`) и безопасным переносом
(неуязвимость, запрет падения, fallback). Подробнее — `PROXY_SETUP.txt`.

### Интеграции
- **PlaceholderAPI**: `%vtregister_authenticated%`, `%vtregister_registered%`,
  `%vtregister_storage%`, `%vtregister_totp%`, `%vtregister_email%`, `%vtregister_waiting%`,
  `%vtregister_mode%`, `%vtregister_antibot_queue%`, `%vtregister_accounts%`.
- **API для плагинов**: `RegisterPluginAPI.get()` + события `AuthLoginEvent`,
  `AuthRegisterEvent`, `AuthLogoutEvent`.
- **Floodgate/Geyser** (Bedrock), **Folia** (региональные планировщики).

### Производительность
- Один фоновый IO-поток для аккаунтов, пакетная запись, грязные записи сбрасываются раз в 2 с.
- Хеширование в пуле с ограничителями (общий и на IP) — CPU не забивается.
- Таймеры антибота работают только при активных проверках.
- Все планировщики — через абстракцию `Scheduler` (Folia-совместимо).

## Команды

| Команда | Кто | Описание |
|---|---|---|
| `/register`, `/reg` | все | регистрация (пароль в чат) |
| `/login`, `/l` | все | вход (пароль в чат) |
| `/changepassword`, `/changepw`, `/cp`, `/passwd` | все | смена пароля |
| `/2fa on\|off\|<код>` | все | двухфакторная аутентификация |
| `/email <адрес>` | все | привязать почту |
| `/recover [код] [новый пароль]` | все | восстановление пароля |
| `/authadmin ...` | `registerplugin.admin` | администрирование (см. ниже) |

`/authadmin reload | status | info | list | reset | unregister | setpw | logout |
forcelogin | setspawn | import | unban`

## Файлы плагина

```
plugins/RegisterPlugin/
├── config.yml          ← основные настройки (комментарии сохраняются)
├── advanced.yml        ← БД, пул, лимиты (для больших серверов)
├── easy-passwords.yml  ← список разрешённых «лёгких» паролей
├── lang/ru.yml, en.yml ← все сообщения
├── LICENSE             ← лицензия (обязательна к соблюдению)
└── data/               ← служебные данные (не для правки вручную)
    ├── accounts.yml / accounts.db
    ├── spawns.yml
    └── lib/            ← автоматически скачанные драйверы
```

## Права

| Право | По умолчанию | Что даёт |
|---|---|---|
| `registerplugin.admin` | `op` | доступ к `/authadmin` |

Игрокам права не нужны — `/reg`, `/l`, `/changepassword`, `/2fa`, `/email`, `/recover`
доступны всем.

## Лицензия

См. файл `LICENSE`. Кратко: использовать бесплатно можно; **нельзя** распространять
без указания автора (Vorchun) и **нельзя** вырезать защиту и безопасность.
Плагин содержит `IntegrityGuard`: при обнаружении вырезанной защиты он выключается.

## Честно о границах

- Ни один Bukkit-плагин не может гарантировать, что другой плагин в том же процессе
  не увидит события/пакеты/память. Защищённый режим перехватывает ввод максимально рано,
  но «абсолютной» защиты в одном процессе не существует.
- Строку `issued server command` пишет само ядро — полностью убрать её можно только
  через `spigot.yml → commands.log: false` (плагин делает это при `command_logging: fix`)
  или log4j-фильтром (включён по умолчанию).
- Folia: планировщик поддерживается, но мир антибот-проверки нужно создать вручную.
- Премиум-автологин работает только на online-mode (или за прокси с IP-forwarding).

## Сборка

```bash
mvn clean package
```

Результат: `target/VTRegister-v1.1.1.jar` (Java 8 bytecode — запускается на Java 8+).
Если Maven не установлен, можно использовать Bundled Maven в IntelliJ IDEA.

Обновления и поддержка: **MineLeak.pro** (профиль Vorchun).
